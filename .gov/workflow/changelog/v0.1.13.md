# StratAtlas v0.1.13

Date: 2026-04-11
Status: Planned release entry for AI provider integration and panel layout fixes

## Highlights

- In-app AI provider configuration: select Claude (Anthropic) or GPT (OpenAI) from the settings menu, enter an API key, validate it with a pre-flight call, and persist the selection securely across restarts using AES-256-GCM encrypted storage.
- Anthropic Claude Messages API backend support alongside the existing OpenAI Responses API path.
- Real MCP protocol client: configure an MCP server command in settings and tool calls route through a real JSON-RPC 2.0 stdio client instead of local simulation. Unconfigured state falls back to the existing simulation with explicit labeling.
- Panel layout stability: persistent Inspector and Tray toggle buttons in the header bar so collapsed panels are always retrievable, footer integrated into the CSS grid so the tray pushes content instead of overlaying, and an intermediate 1320px breakpoint that reduces side panels gracefully.
- Full-DOM snapshot and per-panel capture modes for the visual debugger and headless bridge audit sweep.
- AI gateway governance status correction: REQ-0700..0708 and PRIM-0052/0053 downgraded from E2E-VERIFIED to IMPLEMENTED to match proven reality.

## Operator Notes

- API keys are stored in `<app_data>/stratatlas/credentials/provider_credentials.json` (encrypted). Environment variables (`STRATATLAS_OPENAI_API_KEY`, `STRATATLAS_ANTHROPIC_API_KEY`) still work as fallback.
- MCP server configuration is persisted alongside provider credentials. To use a real MCP server, set the command and arguments in Settings.
- The Ctrl+T keyboard shortcut now toggles the bottom tray panel (matching Ctrl+I for the inspector).
- Current release assets remain under `.product/build_target/Releases/Current/`.
